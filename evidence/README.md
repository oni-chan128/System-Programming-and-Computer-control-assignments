# Q4 Evidence

Run the experiments yourself and place the resulting terminal output/screenshots
here.

Do not create evidence that was not actually observed.

Recommended evidence:

- build.txt
- server-start.txt
- ss-listening.txt
- ps-pstree.txt
- strace-accept.txt
- valid-status.txt
- valid-event.txt
- invalid-input.txt
- oversized-input.txt

For each piece of evidence, record:

1. What command was run?
2. What was observed?
3. What does the observation prove?
4. Which Q4 task does it support?
